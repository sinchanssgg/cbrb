# GCP Deployment

Provisions N VMs on GCP and runs one CRBB experiment.

## Prerequisites

- `terraform` >= 1.5
- `gcloud` authenticated against your project
- `jq`
- A controller running on a reachable IP (see `src/bin/controller.rs`)
- TLS material generated by `controller generate-tls`

## Provision

```bash
terraform init
terraform apply \
  -var project=YOUR_PROJECT \
  -var n=10 -var t=3 -var c=1 \
  -var controller_addr=http://CONTROLLER:8080 \
  -var tls_ca_b64=$(base64 -w0 tls/ca-cert.pem) \
  -var "tls_cert_b64={0=\"$(base64 -w0 tls/nodes/0-cert.pem)\",1=...}" \
  -var "tls_key_b64={0=\"$(base64 -w0 tls/nodes/0-key.pem)\",1=...}"
```

## Run

```bash
./run_sweep.sh
```

## Collect

Metrics land on the controller (`run.json` per experiment). Copy them
to `data/` and run `scripts/aggregate.py`.
